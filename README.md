💀
- Ghost Trace is a cybersecurity and OSINT tool designed to retrieve publicly available IP address information and perform authorized IP tracking demonstrations.

## 🚀 Features

- 🌐 IP LOOKUP
- 🎯 IP TRACKING

## 🌐 1. IP LOOKUP

IP Lookup provides publicly available information about an IP address.

**Features:**
- IP Address Information
- Region & Location
- Country Information
- ISP Details
- Approximate Latitude & Longitude
- Google Maps Location URL
- Public IP Analysis
- IPv4 / IPv6 Support

## 🎯 2. IP TRACKING

IP Tracking demonstrates how public IP addresses can be collected through a tracking link with the visitor's knowledge and consent.

**Features:**
- Generate a tracking URL
- Supports Mobile Phones
- Supports Laptops
- Supports Desktop PCs
- Retrieve public IP address
- Analyze collected IP using IP Lookup
- Ip LookUP working for web sever / web site IP
  
**How It Works:**

1. Generate a tracking URL.
2. Share it with a consenting participant.
3. The participant opens the URL.
4. The tool retrieves their public IP address.
5. Analyze the IP using IP Lookup.
